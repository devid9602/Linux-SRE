# UNIX Operating System Notes

This repository contains chapter notes on **The Design of the UNIX Operating System** by Maurice J. Bach. The repository name is `Linux-SRE`, but the material focuses on classic UNIX kernel and operating-system concepts rather than a broad Linux SRE curriculum.

## How to use these notes

Start with the overview and read the chapters in order. These are personal study notes and are not a replacement for the book or for current Linux kernel documentation. The notes were prepared while studying the book in a course taught by Dr. Vijay Gokhale.

Corrections and clarifications are welcome through pull requests.
